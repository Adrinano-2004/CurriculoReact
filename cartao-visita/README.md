# Cartão de Visita Digital

Atividade de Desenvolvimento Mobile feita com React Native + Expo.

## O que tem no app
- Foto de perfil redonda e nome
- Bio que começa vazia e pode ser editada por um modal
- Switch de notificações (mostra uma mensagem a cada 5 segundos quando ligado)
- Botão Salvar que mostra um Alert

## Como rodar
```
npm install
npx expo start
```
Depois é só abrir no emulador Android (tecla `a`) ou ler o QR Code com o app Expo Go.
